# FAM_OS product identity

FAM_OS means For All Mankind Operating System.

FAM_OS is a local, user-controlled operating-system intelligence service that runs above Linux. It is not a replacement Linux kernel, a firmware image, or an embedded-device operating system.

FAM_OS coordinates local language models, deterministic tools, permissioned application connectors, scoped memory, verification, and hardware-aware scheduling through FAM Core.

Linux remains responsible for processes, memory, filesystems, networking, device drivers, and hardware access. FAM_OS adds an unprivileged intelligence layer and keeps privileged supervision deterministic.

FAM Shell, FAM Console, VS Code connectors, MCP connectors, operating-system adapters, accessibility bridges, and restricted screen/input fallbacks are client or capability surfaces of the same Core policy boundary.

Generated output is not automatically trusted. Code, mathematics, retrieval claims, and application actions are released according to their declared deterministic verification or postcondition policy.
